Every video on this page was recorded on a fresh Amiro with a real model
(OpenCode Go: `muse-spark-1.2-contributor` and `deepseek-v4.1-flash`), the live
web, and real public services. Nothing is scripted or canned: what you see is what the agent did.
They were recorded on a cloud VM, where the keyless search engines return no
results, so in the research clips Amiro says search is unavailable and reads
the official pages directly; with a working engine it searches first. See
[Search](/using/search).
Each one links to the page that explains how to set it up.

## Record these yourself

The videos come from the showcase recordings in `tests/showcase/`. They boot a
throwaway Amiro (never your `~/.amiro`), use the keys in your gitignored
`tests/e2e.config.json`, and write the media to `docs/assets/showcase/`:

```bash
pnpm --dir tests showcase
pnpm --dir tests showcase:export
```
