# 04 — Bell UI

## What is wrong today

`notifications-bell.tsx` (~large single file) mixes feed, detail, filters,
and settings in one popover with ad-hoc styling. The redesign splits it and
adopts Vellum inbox patterns: quiet list rows, category markers, relative
time, unread-first ordering, and a detail view with actions.

## Target structure

| File | Owns |
|---|---|
| `components/notifications/notifications-bell.tsx` | Bell button, unread badge, popover shell (< 150 lines) |
| `components/notifications/notifications-feed.tsx` | Filterable list (All / Unread / per category), rows |
| `components/notifications/notification-detail.tsx` | Selected item: full body, actions, delivery state, resend |
| `components/notifications/notifications-settings.tsx` | Toggles, quiet hours, channel bindings (extracted from bell) |
| `lib/notifications/` | Unchanged shape; gains channel-binding + resend clients |

Rows show category icon + label, title, preview (2-line clamp), relative
time, unread dot; urgency high/critical gets a marker, never color alone.
Detail shows full body, source (chat thread / schedule links), per-channel
delivery state, and actions (View, Resend, Dismiss). Empty states name the
filter ("No unread notifications") with a clear-filter action; loading and
error states are explicit (errors from `ApiError` are shown, not swallowed).

## Standards that apply

- Thin pages, logic in `components/notifications/`, API calls only in
  `lib/backend/` (`ui` skill).
- Every string in `messages/en.json` **and** `messages/hi.json`, same keys
  and `{placeholders}`; `pnpm check:i18n` in Phase 04 exit criteria.
- Theme tokens only (light + dark verified), `ui/*` primitives,
  `lucide-react` icons, `sonner` toasts.
- A11y: icon-only buttons get `aria-label`, list uses list semantics, one
  `h1`-equivalent heading in detail; keyboard reachable throughout.
- `data-testid`s: `notifications-bell`, `notifications-feed`,
  `notification-row-<id>`, `notification-detail`,
  `notifications-settings`, `channel-connect-<channel>`.
