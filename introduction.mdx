Amiro is your own AI agent that you run yourself, on your own computer or your
own server. You talk to it like a person: it researches on the live web,
summarises and files documents, runs work on a schedule, uses your tools
through MCP connectors, works on a desktop of its own, and remembers how you
like things done. It ships as a desktop app and as a self-hosted web app, and
your data stays in your own home directory.

## What you can do

- **Research on the live web.** Ask a question; Amiro searches, reads the
  pages, and answers with tables and sources. [Everyday tasks](/using/everyday-tasks)
- **Summarise and file documents.** Links, PDFs, Office files and images in;
  notes saved to its workspace out. [Workspace files](/using/workspace-files)
- **Put work on a timer.** A weekday morning brief, an inbox cleanup, a weekly
  review — set up by asking. [Schedules](/using/schedules)
- **Connect your tools.** Any MCP server or 1,000+ apps through Composio; the
  agent can add one itself. [Connectors](/using/connectors)
- **Watch it work.** With the sandbox, the agent has its own desktop, streamed
  live into the chat. [Agent desktop](/using/agent-desktop)
- **Build a team.** Specialist agents with their own personality, models,
  connectors and container. [Team](/using/team)
- **Let it remember.** Memory and home files carry who you are into every
  chat. [Memory](/using/memory)
- **Talk instead of type.** Dictation, read-aloud and a hands-free live voice
  room. [Voice](/using/voice)
- **Use it from your phone.** Pair a device with a short code. [Devices](/using/devices)
- **Keep secrets safe.** Keys go to an encrypted vault through secure cards,
  never through the chat. [Credentials](/using/credentials)

## What runs where

Amiro is one product built from four parts in one repository. You do not need
to know this to use it, but it explains why a running Amiro needs no Node.js.

| Part | Path | What it does |
|---|---|---|
| Web UI | `clients/web/src/` | The Next.js app, statically exported so the backend serves it with no Node runtime |
| Backend | `backend/` | The `amiro-backend` service; it serves the UI and the API from one address |
| Runtime | `runtime/` | The `amiro-runtime` agent engine; it runs models, sessions, tools, and provider routing |
| Desktop shell | `clients/desktop/` | The Tauri app that starts the backend and runtime for you on launch |

<Note>
Node.js is only needed to build and test the frontend. A shipped or installed
Amiro runs without it.
</Note>

## Status

Amiro is a working local and single-operator deployment, not a hardened
multi-tenant service. Provider credentials are shared operator credentials, and
tools run with the owner's permissions by default. Run Amiro inside a VM or
sandbox and keep it bound to loopback unless you have put TLS and a real network
boundary in front of it.

<Warning>
Before you expose Amiro to anyone but yourself, read
[Settings and the security model](/settings/overview-tour). The restrictions are
enforced by Amiro's own code, not by the operating system.
</Warning>
