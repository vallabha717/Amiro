This is the shortest path from nothing to a useful answer. It uses the server
installer (Linux and macOS). For the desktop app, see
[Installation](/installation): the steps after install are the same.

<Info>
You need one model provider. Amiro ships no models and no default password.
The videos here use **OpenCode Go** with `muse-spark-1.2-contributor`; any
provider in the catalog works the same way.
</Info>

<Steps>
  <Step title="Install Amiro">
    ```bash
    curl -fsSL https://github.com/vallabha717/Amiro/releases/latest/download/install.sh | bash
    ```

    The installer picks the build for your OS and CPU, checks its SHA-256,
    installs under `~/.amiro/app/<version>`, links `amiro` into
    `~/.local/bin`, and starts the server. It prints the address to open
    (usually `http://127.0.0.1:3000`).

    On a VM you reach over the network, and to keep it running across reboots:

    ```bash
    curl -fsSL https://github.com/vallabha717/Amiro/releases/latest/download/install.sh | bash -s -- --public --service
    ```
  </Step>

  <Step title="Create the owner account">
    Open the address and click **Get started**. Enter what the agent should call
    you, an email or username, and a password of at least 12 characters. There
    is no sign-up and no cloud account: this is the only account, the owner.

    <Tip>
    There is no email recovery. If you forget the password, run
    `amiro reset-password` on the machine running Amiro.
    </Tip>
  </Step>

  <Step title="Follow the setup chat">
    Amiro now sets itself up as a chat, one step at a time, and you answer each
    step with a card:

    | Step | What you do | Can skip? |
    | --- | --- | --- |
    | Look | Pick a plush shape and a colour | Yes |
    | Default prompt | Read `IDENTITY.md` and `SOUL.md`, the instructions it works from | Yes |
    | Personality | Pick a preset (Warm Companion, Sharp Operator…) | Yes |
    | Brain | Search the provider catalog, pick one, connect it | Yes, but you need it to chat |
    | Web search | Bing and DuckDuckGo need no key; Brave, Tavily, Exa… take one | Yes |
    | Connectors | Composio key or an MCP server | Yes |
    | Voice and listening | Speech engines for read-aloud, dictation and live voice | Yes |
  </Step>

  <Step title="Connect your provider">
    On **Brain**, type the provider's name (for example *OpenCode Go*), pick it
    and paste its API key into the masked field, then **Save key**. The key goes
    straight to the encrypted vault. It is never shown again and never enters
    the chat. Subscription sign-ins (OAuth, device code) and local
    OpenAI-compatible endpoints are in the same catalog.
  </Step>

  <Step title="Pick a keyless web search">
    On **Web search**, click **Bing Search** or **DuckDuckGo**. That is all it
    takes for Amiro to research on the live web from a home connection. On a
    cloud VM, the keyless engines often get a challenge page and no results:
    add a Brave (free tier) or Tavily key there instead.
  </Step>

  <Step title="Choose your default model">
    Open **Admin → Models & Providers**. On the provider card, click **Set
    default** next to the model you want (here `muse-spark-1.2-contributor`),
    then **Models & test → Run model test** to check it answers.

    <Frame caption="Default model on the provider card, a model test, and the composer's model picker.">
      <video controls muted playsInline preload="metadata" poster="/docs/assets/showcase/setup-model.jpg" src="/docs/assets/showcase/setup-model.mp4" />
    </Frame>
  </Step>

  <Step title="Ask something real">
    Open a new chat and try:

    ```text
    Search the web and compare Obsidian, Logseq and Joplin for personal notes today.
    Give me a table and cite the pages you used.
    ```

    <Frame caption="A real answer from the live web, with a table and sources.">
      <video controls muted playsInline preload="metadata" poster="/docs/assets/showcase/research.jpg" src="/docs/assets/showcase/research.mp4" />
    </Frame>
  </Step>
</Steps>

## If you skipped a step

- Each skipped step leaves a reminder card at the bottom of the sidebar that
  links straight back to it.
- Run the whole setup chat again any time from **Admin → General**.
- Connect providers any time in **Admin → Models & Providers**, or type `/login`
  in the composer.
- Reach a VM's Amiro without exposing it:
  `ssh -L 3000:127.0.0.1:3000 you@your-vm`, then open `http://127.0.0.1:3000`.
